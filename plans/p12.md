# P12 Plan — Structured Binary Program Head for Exact Valid-Set NLL

**Date:** 2026-08-13  
**Status:** Prospective bounded experiment only  
**Prerequisite:** P11 completed with **Outcome C — input signal exists, but factorized top-1 remains poor**  
**Do not launch full matched training automatically.**

---

## 1. Motivation

P11 established two facts that must be kept separate.

### 1.1 Probability-level input signal exists

Under exact valid-set NLL, the question-conditioned predictor assigned more probability mass to the target sample's valid route set when given the aligned question than when given a deterministic within-dataset shuffled question.

```text
Aligned set-NLL  = 14.8699
Shuffled set-NLL = 15.5089
Difference       = 0.6390
```

Therefore, the frozen Qwen3 question encoder + POLAR-style cross-attention/cross-layer encoder is not completely input-blind.

### 1.2 Complete-mask decoding remains nearly constant

The selected P11 exact-set checkpoint decoded:

```text
147 / 150 validation masks = ALL-ON
57 / 60 execution masks    = ALL-ON
```

The three non-FULL execution masks were uncached and all remained wrong.

Thus P11 showed a **probability-to-decoding gap**:

```text
question-dependent probability structure
                ↓
         factorized 28-bit head
                ↓
     almost-constant top-1 mask
```

P12 tests whether a structured output representation can convert the already-detected input signal into coherent nonconstant executable routes.

---

# 2. Primary research question

> **Does replacing the direct factorized 28-bit ON/OFF output representation with a structured contiguous-segment representation improve complete-mask decoding under the same exact valid-set NLL and the same predictor backbone?**

This is an architecture-isolation experiment.

The main comparison is:

```text
P11:
same encoder
+ direct factorized 28-bit head
+ exact valid-set NLL

vs.

P12:
same encoder
+ structured segment head
+ exact valid-set NLL
```

Do not change the data, encoder, MCTS labels, weighting rule, optimizer family, route executor, or compute objective.

---

# 3. Claim boundary

P12 is **not** designed to prove that segment factorization fully models arbitrary cross-layer dependence.

The intended claim, if successful, is narrower:

> **A structured contiguous-program representation is a better output inductive bias than independent bit thresholding for converting input-conditioned probability signal into coherent binary visual-computation masks.**

Do not claim that P12 "solves cross-layer dependency" unless a later experiment directly establishes that stronger statement.

# 6. P12-B — Freeze the canonical mask ↔ segment mapping

Use one deterministic canonical representation only.

## 6.1 Primary canonical rule

Use **maximal contiguous runs of equal binary values**.

Example:

```text
111111000011
→
111111 | 0000 | 11
→
[0:6] ON
[6:10] OFF
[10:12] ON
```

Do not introduce POLAR's `Kmax=4` in the primary P12 smoke unless an existing repository implementation makes that constraint unavoidable.

Reason:

```text
P12 must represent the existing 28-bit supervision losslessly.
Artificially splitting a long run into smaller same-operation segments adds
representation ambiguity without changing the executable mask.
```

## 6.2 Round-trip requirement

For every selected supervision mask:

```text
mask
→ canonical segments
→ reconstructed mask
```

must satisfy:

```text
reconstructed_mask == original_mask
```

bit-for-bit.

Required gate:

```text
100% round-trip accuracy
0 ambiguous canonicalizations
0 missing masks
```

Do not train until this passes.

# 7. Structured output representation

For each of the 28 layer positions, retain the existing input-conditioned layer representation produced by the unchanged POLAR-style encoder.

Replace the direct binary ON/OFF head with two heads.

## 7.1 Boundary head

Predict:

```text
b_i ∈ {0,1}
```

where:

```text
b_i = 1
```

means layer `i` starts a new segment.

Layer 0 must always be a segment start.

The canonical boundary labels are determined from the maximal-run representation.

Example:

```text
mask:
111100011

boundary:
1 0 0 0 1 0 0 1 0
```

## 7.2 Segment-operation head

At segment-start positions only, predict:

```text
operation ∈ {ON, OFF}
```

Labels at non-segment-start positions are ignored.

Example:

```text
[0:4] ON
[4:7] OFF
[7:9] ON
```

gives operation labels at starts:

```text
layer 0 → ON
layer 4 → OFF
layer 7 → ON
```

## 7.3 Deterministic top-1 decoding

Freeze one deterministic decoder before looking at model outcomes.

Recommended first decoder:

1. force boundary at layer 0;
2. threshold boundary probabilities at `0.5` for layers 1–27;
3. construct contiguous segments;
4. at each predicted segment start, choose `argmax(ON, OFF)`;
5. fill the selected operation across the segment;
6. obtain one executable 28-bit mask.

Do not add beam search in P12.

Do not tune the threshold from execution outcomes.

# 8. Exact structured valid-set probability

Keep the **one-of-valid-set exact NLL principle** from P11.

For each valid binary mask `m`, convert it deterministically to its canonical structured representation:

```text
r(m) = (boundaries, segment operations)
```

The model must assign a log probability to that complete canonical representation.

Conceptually:

```text
log P(r(m) | x)
=
log P(boundaries(m) | x)
+
log P(segment_ops(m) | boundaries(m), x)
```

The boundary term is a Bernoulli log-likelihood over the 28 boundary labels.

The operation term is a categorical ON/OFF log-likelihood evaluated only at the canonical segment starts.

Then use:

```text
L_set(x)
=
-log Σ_{m ∈ V_x} w_m P(r(m) | x)
```

with stable `logsumexp`.

---

# 9. Important probability-definition check

Before real training, verify that the chosen structured probability is internally consistent.

At minimum:

- boundary probability is finite for every selected mask;
- operation probability is evaluated only at canonical segment starts;
- padded valid routes contribute zero mass;
- duplicate masks are deduplicated exactly as in P11;
- route weights match P11;
- gradients reach the structured predictor only;
- frozen Qwen3 encoder components remain frozen wherever P11 froze them.

Document the exact formula in the implementation report.

# 18. Primary P12 success criteria

P12 success requires more than lower set-NLL.

All of the following categories must be considered.

## Gate A — Probability-level conditioning survives

Required:

```text
Aligned structured set-NLL < Shuffled structured set-NLL
```

The structured representation must not destroy the P11 input signal.

## Gate B — Constant mode is materially reduced

P11 selected exact checkpoint:

```text
98% ALL-ON on 150 route-validation records
```

P12 should show a material reduction in constant-route collapse.

Do not define success merely as `97%` instead of `98%`.

Report the exact magnitude and route diversity.

## Gate C — Decoded route quality improves

P12 should improve complete-mask metrics relative to P11:

```text
Hit@1 and/or
nearest-valid Hamming and/or
executed behavior
```

The main priority is actual execution, not native segment-label accuracy.

## Gate D — Useful non-FULL execution exists

On the frozen 60-record execution subset:

```text
W→C > 0
```

is strong preferred evidence.

At minimum, non-FULL selections must demonstrate some real execution utility rather than only diversity.

## Gate E — Regression remains controlled

Any new corrections must be considered jointly with:

```text
C→W
```

A model that gains route diversity by causing widespread FULL-correct regressions does not pass.

# 19. Decision outcomes

At the end of P12, select exactly one outcome.

## Outcome A — Structured representation succeeds

Use if:

```text
aligned > shuffled remains clear,
decoded masks become materially nonconstant,
complete-mask/execution behavior improves over P11,
and useful non-FULL routes appear without unacceptable regressions.
```

Interpretation:

> The P11 probability-to-decoding gap was at least partly an output-representation bottleneck.

Recommendation:

```text
authorize a separate full matched-training plan
```

but do not launch it without explicit user approval.

---

## Outcome B — Structured representation also collapses

Use if:

```text
decoded masks remain nearly constant
and
actual execution remains equivalent to FULL / global constant behavior.
```

Interpretation:

> The P11 failure is not explained sufficiently by independent-bit decoding alone.

Kill the structured-head pivot.

Do not respond by stacking more architectural modules.

Return to the broader question of whether the current input features / supervision contain enough deployable route-selection signal.

---

## Outcome C — Diversity improves but execution does not

Use if:

```text
ALL-ON collapse is reduced
and masks become diverse
but
W→C remains zero / regressions increase / uncached masks remain mostly wrong.
```

Interpretation:

> Structured decoding breaks the constant mode, but route diversity is not utility-aligned.

Do not full-train.

Next work should reconsider supervision/ranking/utility alignment rather than adding more route-structure complexity.
